# Задача: текст для каруселі (SMM)

Напиши текст для каруселі: що написано на кожному слайді, ідеї по візуалу, текст для допису й сторіз-репост, яким допис поширюють у сторіс.

## Вхідні дані

Перевір, чи є все, чого вимагає скіл проєкту: тема, рубрика, мета; для акції — умови (відсоток, категорії, дати). Якщо CTA проєкту різний для Instagram і Facebook, а майданчик не названо — спитай. Чого бракує, назви одним коротким списком і зупинись. Якщо людина відповідає «вирішуй сам», припусти найімовірніше, напиши припущення одним рядком і працюй.

## Слайди

- «Слайд 1», «Слайд 2»… — текст кожного слайда окремо. Кількість — як попросили, інакше 5–7.
- Слайд 1 — обкладинка: зупиняє скрол і прямо називає тему.
- Один слайд — одна думка. Текст на слайді короткий: заголовок і кілька рядків.
- Слайди йдуть логічно один за одним; останній — висновок або CTA за правилами проєкту.

## Текст для допису

- Перший рядок — гачок: його видно до «більше».
- Підпис доповнює слайди: що вже написано на них, дослівно не повторюй; розкрий, поясни, запроси погортати, якщо це природно для проєкту.
- Кінець веде до CTA за правилами проєкту.

## Сторіз-репост

Затравка для репосту допису з каруселлю у сторіс. Формат — два коротких абзаци, без ідей по візуалу:

1. Питання-гачок до аудиторії про її потребу чи сумнів + один доречний емодзі.
2. Суть одним реченням (що й коли) + відсилка до публікації: «Розповіли в новому дописі».

Зміст слайдів не переказуй і окремого CTA не додавай: відсилки до публікації достатньо.

Приклад формату сторіз-репосту. Він з іншого проєкту: бери з нього лише структуру, довжину й інтонацію, а факти, назви й дати не переноси.

Тон, звертання, емодзі, CTA, табу — за скілом проєкту. Цифри, ціни й умови — лише з повідомлень людини або з фактів у скілі проєкту, з позначками, яких він вимагає.

## Видача

1. Слайди «Слайд 1…».
2. Окремий блок «Ідеї по візуалу» — по слайдах.
3. «Текст для допису:».
4. «Сторіз-репост:» — два абзаци затравки, без ідей по візуалу.
5. Останній блок «Що потребує копірайтера»: усі [УТОЧНИТИ], [ПІДТВЕРДИТИ У КЛІЄНТА], ризиковані місця. Якщо нічого — блок не пиши.

Перед видачею сам пройди 8 критеріїв і мовні норми базового скіла та виправ знайдене. Картку оцінки не показуй.
