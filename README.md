# Telegram-бот агенції для роботи з текстами

Меню бота: **напрям → проєкт → задача**. Під кожен проєкт і кожну задачу підключено окремий скіл.

## Як це виглядає для людини

1. **/start.** Новий користувач натискає «📱 Поділитися номером» (Telegram підставляє номер сам), потім пише ім'я та прізвище. Тобі (адміністратору) приходить запит з **іменем, телефоном, @ніком і ID** і кнопками «✅ Дозволити» / «❌ Відхилити».
2. Після підтвердження людина бачить **правила користування** (файл `rules.txt`) і кнопку «✅ Ознайомився(-лась)».
3. **Напрям:** зараз доступний лише SMM. Target і TikTok уже описані в меню, але вимкнені.
4. **Проєкт:** ОЛДІ, СМЦ.
5. **Задача** (для SMM):
   - Вичитка наявного тексту
   - Текст для сторіс
   - Текст для допису → **Статика** або **Reels** (для Reels можна надіслати сценарій, і текст буде на його основі)
   - Текст для каруселі (слайди + ідеї по візуалу + підпис)
6. Людина надсилає текст або бриф. Бот може поставити уточнювальні питання, і на них відповідають звичайним повідомленням. Правки пишуть так само: «коротше», «інший перший кадр».

Під кожною відповіддю є кнопки:
- **📋 Картка оцінки** — лише у вичитці;
- **🆕 Новий текст** — почати діалог з чистого аркуша в тій самій задачі;
- **🔀 Інша задача** — інша задача того ж проєкту;
- **☰ Меню** — повернутися до вибору напряму.

### Команди

- `/start` — правила й початок роботи.
- `/menu` — вибір напряму, проєкту й задачі.
- `/users` — тільки для адміністратора: команда. Натискаєш на людину, бачиш картку (ім'я, телефон, @нік, дата) і кнопку «🚫 Заблокувати». Заблоковані в окремому списку, звідти можна розблокувати.
- `/add ID Ім'я` — тільки для адміністратора: запросити людину за Telegram ID. Після /start вона поділиться номером та ім'ям і зайде без окремого підтвердження.

## Як складається «мозок» для кожної задачі

Коли людина обирає, наприклад, SMM → ОЛДІ → Текст для сторіс, бот бере три скіли:

| Шар | Файл | Що містить |
|---|---|---|
| Базовий скіл напряму | `skills/base/vychytka-tekstiv.md` | мовні норми й 8 критеріїв |
| Скіл проєкту | `skills/smm/kopyrayter-oldi.md` | тон, CTA, факти, табу клієнта |
| Скіл задачі | `skills/tasks/smm-storis.md` | що саме зробити і в якому вигляді віддати |

Усе це описано у **`menu.json`**.

## Як додати проєкт, задачу чи напрям

**Новий проєкт** (наприклад, скіл, зібраний через «make-kopyrayter»):
1. Поклади файл скіла в `skills/smm/kopyrayter-<клієнт>.md`.
2. У `menu.json` у розділі потрібного напряму допиши проєкт у список `projects`:
   ```json
   { "id": "novyi", "name": "Назва на кнопці", "skill": "skills/smm/kopyrayter-novyi.md" }
   ```
3. Перезапусти бота.

**Підваріанти задачі** (як «Статика / Reels» у «Тексті для допису») задаються полем `variants` у задачі: кожен варіант має свій `id`, `name`, `skill` і `hint`.

**Окремий скіл задачі саме для одного проєкту** (наприклад, особливі сторіз для ОЛДІ) задається полем `task_skills`. Для варіанта ключ пишеться через крапку: `"post.reels"`.
```json
{ "id": "oldi", "name": "ОЛДІ", "skill": "skills/smm/kopyrayter-oldi.md",
  "task_skills": { "stories": "skills/smm/oldi-storis.md" } }
```

**Увімкнути Target або TikTok.** Їхні кнопки вже прописані в `menu.json`:
- Target: вичитка наявного тексту, написання сценарію, ТЗ для дизайнера під банер;
- TikTok: вичитка наявного сценарію, написання сценарію, ресерч ідей під проєкт.

Щоб увімкнути напрям:
1. Додай проєкти в його `projects`.
2. Для кожної задачі вкажи файл скіла в полі `skill`.
3. Постав `"enabled": true` і перезапусти бота.

Напрям з'являється в меню лише тоді, коли в ньому є хоча б один проєкт.

`id` у `menu.json` пиши латиницею (малі літери, цифри, `_`, до 15 символів). `name` — це те, що бачить людина на кнопці.

## Налаштування

У файл `.env` вписуються три значення:

| Що | Де взяти | Рядок у `.env` |
|---|---|---|
| Токен бота | Telegram → **@BotFather** → `/newbot` | `TELEGRAM_BOT_TOKEN=` |
| Твій Telegram ID | **@userinfobot** покаже ID (лише цифри). Ти адміністратор. | `ADMIN_IDS=` |
| Ключ Anthropic API | **console.anthropic.com** → Settings → API Keys. У **Billing** поповни баланс. Підписка Claude Pro/Max на API **не поширюється**. | `ANTHROPIC_API_KEY=` |

```bash
cp .env.example .env
```

> ⚠️ Токени нікому не пересилай, зокрема в чат. Вони мають бути тільки у файлі `.env`.

> Після запуску сам один раз натисни `/start` у боті. Інакше Telegram не дозволить ботові написати тобі про чужі запити на доступ.

## Запуск на Mac/ПК

Потрібен Python 3.10 або новіший.

```bash
cd telegram-edit-bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Бот працює, поки відкрите вікно термінала й комп'ютер не спить. Зупинити його можна клавішами `Ctrl+C`.

## Запуск 24/7 на Railway (рекомендовано для команди)

1. Код бота має лежати в приватному репозиторії GitHub.
2. railway.com → увійти через GitHub → **New Project → Deploy from GitHub repo** → обрати репозиторій. Railway сам знайде `Dockerfile`.
3. Вкладка **Variables** → додати три змінні: `TELEGRAM_BOT_TOKEN`, `ADMIN_IDS`, `ANTHROPIC_API_KEY`.
4. Правою кнопкою на сервісі → **Attach Volume** → шлях `/app/data`. Там зберігається список людей із доступом, без цього він зникатиме після кожного оновлення.
5. Дочекатися статусу **Active** і натиснути `/start` у боті.

Після кожного оновлення коду в GitHub Railway сам перезапускає бота. Ціна — від $5 на місяць.

Важливо: бот має працювати лише в одному місці. Якщо він запущений на Railway, на Маку його не запускай: Telegram віддає повідомлення тільки одній копії.

## Запуск 24/7 на власному сервері (VPS)

```bash
docker build -t edit-bot .
docker run -d --restart=always --env-file .env -v "$(pwd)/data:/app/data" --name edit-bot edit-bot
```

У папці `data/` зберігається список людей із доступом. Діалоги живуть у пам'яті й після перезапуску бота зникають: людина просто натискає «🆕 Новий текст».

## Додатково

- `BOT_CLAUDE_MODEL`: модель, за замовчуванням `claude-opus-5-5`.
- `BOT_CLAUDE_EFFORT`: `low` / `medium` / `high` (за замовчуванням `medium`).
- Ти платиш Anthropic за кожну відповідь бота. Скіли кешуються, тому повторні запити дешевші. Точні витрати видно в console.anthropic.com → Usage.
